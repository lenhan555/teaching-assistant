# Teaching Assistant

An AI-powered content and grading system for Excel, SQL, and Power BI training courses. Instructors use it to generate course materials and grade student homework — the agents handle the mechanical work, freeing instructors for mentorship and live teaching.

---

## What It Does

| Task | How to trigger | What you get |
|------|---------------|--------------|
| Build course materials for a new topic | `/course-prep` | Knowledge doc, slide deck, 2 assignments, grading rubric |
| Grade text/SQL submissions for a cohort | `/grade-cohort` | Per-student feedback files + cohort insight report |
| Grade Excel workbook submissions | `/grade-excel-cohort` | Per-student feedback files + cohort insight report |
| Research a single topic | `/sql-knowledge-research-update` | Structured knowledge doc |
| Generate a slide deck | `/slide-deck` | Slide-by-slide PPT blueprint |

---

## Prerequisites

- **Claude Code** (claude.ai/code) — all commands run through Claude Code's CLI or desktop app
- **Python 3** with `openpyxl` — required for Excel grading only

```bash
pip3 install openpyxl
```

## Quick Start

### 1. Prepare a new topic from scratch

Run this one command and the system builds everything:

```
/course-prep sql joins beginner
```

This runs five agents in sequence and produces:
- `skills/sql-beginner-joins.md` — structured knowledge doc
- `slide_deck_template/decks/sql-beginner-joins.md` — slide deck blueprint
- `assignments/sql-beginner-joins-take-home.md` — graded homework
- `assignments/sql-beginner-joins-in-class.md` — live practicals
- `rubrics/sql-beginner-joins-rubric.md` — grading rubric

**Options:**

```
/course-prep <subject> <topic> <level> [--audience <audience>] [--style <style>]
```

| Argument | Values |
|----------|--------|
| `subject` | `sql`, `excel`, `powerbi` |
| `level` | `beginner`, `intermediate`, `advanced` |
| `--audience` | `students` (default), `executives`, `clients` |
| `--style` | `training` (default), `pitch`, `report` |

---

### 2. Grade text/SQL submissions

Put one file per student in a folder, then run:

```
/grade-cohort joins beginner submissions/may-cohort-joins/
```

Student files should be named `[student-id].md` or `[student-id].sql` (e.g. `ana-santos.md`).

**Requires:** a rubric at `rubrics/sql-beginner-joins-rubric.md`. If no rubric exists, run `/course-prep` first or the rubric-builder agent manually.

**Produces:**
- `grades/joins-[student-id]-feedback.md` — one per student (score breakdown, strengths, next steps)
- `log/cohort-[cohort-id]-joins-feedback.md` — cohort report with top weak concepts and re-teach recommendations

---

### 3. Grade Excel workbook submissions

Put one `.xlsx` file per student in a folder — each workbook should have one sheet per completed lesson. Then run:

```
/grade-excel-cohort excel beginner may-2026 submissions/may-2026/
```

**Arguments:**

| Argument | Required | Description |
|----------|----------|-------------|
| `subject` | yes | `excel`, `sql`, or `powerbi` |
| `level` | yes | `beginner`, `intermediate`, or `advanced` |
| `cohort_id` | yes | Short identifier, e.g. `may-2026` |
| `submissions_dir` | yes | Folder containing student `.xlsx` files |
| `--assignments` | no | Override default `assignments/` directory |

**Requires:**
- Assignment files in `assignments/` named as `excel-beginner-[topic]-take-home.md` — the system matches sheet names to these files automatically
- `openpyxl` installed (see Prerequisites)

**Produces (for each student):**
- `agents/excel-scanner/output/[student-id]-scan.md` — extracted sheet contents
- `agents/excel-reconciler/output/[student-id]-reconciliation.md` — task-by-task completion status
- `grades/excel-beginner-may-2026-[student-id]-feedback.md` — final graded feedback

**Plus one cohort report:**
- `log/cohort-may-2026-excel-beginner-feedback.md`

**Example with 3 students** (`ana-santos.xlsx`, `david-kim.xlsx`, `priya-mehta.xlsx`):

```
/grade-excel-cohort excel beginner may-2026 submissions/may-2026/
```

## Folder Structure for Instructors

```
Teaching Assistant/
├── submissions/              ← PUT student files here (create per cohort)
│   └── may-2026/
│       ├── ana-santos.xlsx
│       └── david-kim.xlsx
├── assignments/              ← Assignment markdown files (generated by /course-prep)
├── rubrics/                  ← Grading rubrics (generated by /course-prep)
├── grades/                   ← Per-student feedback (written by grading agents)
├── log/                      ← Cohort reports and activity logs
└── skills/                   ← Knowledge docs (generated by research agents)
```

You only need to manage `submissions/`. Everything else is written by the agents.

## Individual Skills

Use these when you want to run one step on its own rather than the full pipeline.

### Research a topic

```
/sql-knowledge-research-update beginner joins --update
```

Fetches from SQL documentation and recent sources, then merges findings into `skills/sql-beginner-joins.md`. Without `--update`, prints to screen only.

Also available:
- `/excel-knowledge-research-update [level] [topic] [--update]`
- `/power-bi-knowledge-research-update [level] [topic] [--update]`

### Generate a slide deck

```
/slide-deck "SQL Joins for Beginners" --slides 12 --style training --save
```

Produces a slide-by-slide blueprint with layout specs, headlines, content, and PowerPoint build notes. Saved to `slide_deck_template/decks/sql-joins-for-beginners.md`.

### Build a rubric

```
/rubric-builder
```

Generates a grading rubric from an existing assignment file. Output: `rubrics/[subject]-[level]-[topic-slug]-rubric.md`.

### Generate an assignment

```
/assignment-generator
```

Produces a take-home or in-class assignment from a knowledge doc. Output: `assignments/[subject]-[level]-[topic-slug]-take-home.md`.

## How the Agent System Works

Each workflow is orchestrated by a squad of specialized agents, each with a single responsibility:

| Agent | Does |
|-------|------|
| **Researcher** | Fetches and summarizes information from authoritative web sources |
| **Synthesizer** | Merges research into a clean, structured knowledge document |
| **Slide Generator** | Turns a knowledge doc into a slide deck blueprint |
| **Assignment Generator** | Writes take-home and in-class exercises |
| **Rubric Builder** | Derives grading criteria from an assignment file |
| **Excel Scanner** | Extracts cell values, formulas, charts, and pivots from `.xlsx` files |
| **Excel Reconciler** | Matches each sheet to a lesson assignment; judges task completion |
| **Grading Agent** | Scores a student's work and writes constructive feedback |
| **Cohort Feedback** | Aggregates results across the cohort; flags weak concepts |

Agents write their outputs to `log/` when they finish. If a student fails partway through, the system skips that student and continues — it never aborts an entire cohort run for a single error.

## Naming Conventions

| Item | Convention | Example |
|------|-----------|---------|
| Student ID (from filename) | Lowercase, hyphens | `ana-santos` |
| Assignment file | `[subject]-[level]-[topic-slug]-take-home.md` | `excel-beginner-vlookup-take-home.md` |
| Rubric file | `[subject]-[level]-[topic-slug]-rubric.md` | `sql-beginner-joins-rubric.md` |
| Student feedback | `[subject]-[level]-[cohort-id]-[student-id]-feedback.md` | `excel-beginner-may-2026-ana-santos-feedback.md` |
| Cohort report | `log/cohort-[cohort-id]-[subject]-[level]-feedback.md` | `log/cohort-may-2026-excel-beginner-feedback.md` |

The Excel grading pipeline matches sheet names to assignment files by keywords. For the match to work, **assignment filenames must include the subject and level**, and the sheet name should contain the topic keyword (e.g., a sheet named "Lesson 3 - VLOOKUP" will match `excel-beginner-vlookup-take-home.md`).
