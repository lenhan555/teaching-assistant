# Memory Index — SlideQC Agent

- [SQL Headline Size Drift](pattern-sql-headline-size-drift.md) — Dark-slide headline font sizes drift below 36pt spec in SQL decks; most common on slides with long JOIN-type names
- [SQL Off-Palette Colors](pattern-sql-off-palette-colors.md) — SQL decks use off-palette colors in two ways: blue/yellow/purple tints in summary tables AND red (#CC3333) in "Watch Out" slide headlines — both violate design system
- [SQL Density Spike at End Slides](pattern-sql-density-end-slides.md) — Beginner SQL decks exceed 30-word limit on wrap-up slides; exercise slides crammed with 3-4 items; best-practice checklists exceed 5 items
- [Redundant Objectives Slide](pattern-redundant-objectives-slide.md) — Decks with both Agenda + Learning Objectives slides in opening section duplicate content; replace Objectives with a motivating "Why X Matters" slide
