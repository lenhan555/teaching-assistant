Core JOINs

◈ INNER JOIN** — Returns only matched rows from both tables. Silent row drops if a key is missing on either side. Use when a match must exist.
4

Outer JOINs

◈
RIGHT JOIN** — Mirror of LEFT JOIN. All right-table rows; NULLs fill left side. Almost always rewritable as LEFT JOIN with swapped table order. Avoid mixing LEFT and RIGHT JOIN in the same query.
5

Special JOINs

CROSS JOIN** → Result rows = Table A rows × Table B rows. No ON clause. Use for product matrices, calendar grids, test data. Risk: 1,000 × 1,000 = 1,000,000 rows
sanity-check row counts first.
